# What is Secure TASM

[Secure TASM](https://secure-tasm.lozdo.com) is a cloud service designed for easy file storage and sharing. Here are the key features of the application

## Features

![Secure TASM](/assets/image/image1.png)

- **Secure**

    Securely stored on our own servers and encrypted media. Please use with confidence. Secure is important.

- **Easy to Share**

    Strictly control file access by precisely specifying authorized individuals for each file, ensuring secure sharing.

- **High Availability**

    Powered by [Amazon S3](https://en.wikipedia.org/wiki/Amazon_S3) for exceptional reliability, scalability, and seamless content delivery.

## Use Case

Here are some typical use cases for Secure TASM:

- **Cross-Platform File Transfer**

    Transferring files between different operating systems can often be cumbersome. As a web application, Secure TASM allows you to access your files from any browser regardless of the OS. Furthermore, since your data is linked to your account rather than shared via temporary URLs, there is no need to manually transfer files between devices.

- **High-Security Requirements**

    When maximum security is required, Secure TASM lets you enable [**E2EE (End-to-End Encryption)**](https://en.wikipedia.org/wiki/End-to-end_encryption) with a single click. This ensures that no one—not even the server administrators—can view your files, guaranteeing the highest level of privacy and protection.

- **Flexible File Sharing**

    Sharing files with various people is simple. If the recipient is a Secure TASM user, you can easily share files just by specifying their email address. Additionally, we plan to implement an **Express Link** feature in the future, allowing you to share files via a time-limited URL even with non-Secure TASM users.

## Developer

Secure TASM is an open-source project. All source code is publicly available in our GitHub repository: **[github.com/youtame/toritsudaigaku](https://github.com/youtame/toritsudaigaku)**.

Our goal is to make the codebase accessible and usable for as many developers as possible.

### Key Development Details

- **Open Source & Contribution**

    We welcome community involvement. If you find any issues, security concerns, or have feature requests, please feel free to open an issue or submit a pull request on GitHub.

- **Modern Tech Stack**

    The entire codebase is built using widely adopted, developer-friendly technologies, primarily **Vue.js** and **TypeScript**. This makes it easy for developers of various backgrounds to understand, audit, and contribute to the project.
